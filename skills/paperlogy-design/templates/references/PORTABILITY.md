# Portable bundle
Extract core ZIP and every needed category ZIP to the same parent directory. All archives have a deck-replica/ prefix. Keep scripts/, references/, assets/ together; no original drive path required. The full catalog has189 entries; an omitted category produces a normal missing-file error and must be extracted before use.

Requirements: Python3, lxml, Pillow. For native edit/save QA, python-pptx. PDF preview validation uses LibreOffice and PyMuPDF. No web service, credential or API required.

Five PPTX packs are editable static templates, not screenshot pages. Original font binaries are not included. Source61,148,420,554 and others visibly wrap differently in LibreOffice due typography substitution; preserve fonts for faithful PowerPoint use or reflow copied text after choosing a supported fallback. Templates have not all been manually re-typeset. The packaged previews show actual LibreOffice rendering, not the original PDF pretending to be output.
