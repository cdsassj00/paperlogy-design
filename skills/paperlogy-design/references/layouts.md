# Paperlogy 레이아웃 아키타입 카탈로그

`assets/paperlogy-deck.html`에 전부 구현돼 있다. 각 슬라이드는 `<section class="slide" data-layout="K03">` 형태.
새 덱은 이 파일을 복사해 필요한 아키타입만 남기고 내용을 교체한다. 좌표는 1280×720 캔버스 기준.

## 목차
- 모드 선택
- C: 표지·목차·엔딩 C01~C03
- K: 키노트(발표형) 아키타입 K01~K17
- R: 리포트(보고형) 아키타입 R01~R04 + 부품 클래스
- 덱 리듬(시퀀스) 패턴 + 덱 길이별 축약 규칙

---

## 모드 선택

| 모드 | 언제 | 배경 | 밀도 |
|---|---|---|---|
| **KEYNOTE** | 발표·강의·외부 PT·런칭·유튜브형 | 검정 + 오로라/사진 | 1장 1메시지, 여백 의도적(slide-density 히어로 예외) |
| **REPORT** | 사내 보고·제안서 본문·인쇄 배포 | 라이트(#FFF) 또는 다크(#222→#030303) 템플릿 | slide-density 전면 적용(빈 띠 ≤12%) |

한 덱 안에서 섞을 수 있다: 표지·간지·매니페스토=KEYNOTE, 본문 근거=REPORT.

### K 공통 디테일
- 제목 끝 마침표(.)는 `<i class="dot">.</i>` — 색은 `--dot` 토큰(기본 핑크).
- 검정 위 강조 글자는 `.c-accent`(= `--accent-on-dark`, 밝은 변형). 구체·사진 위 글자는 `.on-orb`(그림자)로 대비 확보.
- 비활성(일부러 죽인) 텍스트는 `data-dim` 속성 — 대비 검사에서 제외된다.
- 영문 라벨(PRINCIPLE, STEP 01, FORECAST)은 Montserrat 800–900, 대문자, 작게(12–16px).
- 우측 카드·사진·타일엔 못(nail) 4개: `.nails.n-corner | n-plus | n-circle | n-text`.

## R — 리포트 아키타입

### R01 라이트 리포트 (#9-14, 128-131, 219-220)
```
y 3–5%   [헤더 좌: 프로젝트 대제목 12px]                     [헤더 우: 현재 위치 · 목차 12px]
y 8.5%   ───────── 1px 그라데이션 헤어라인(#FF2F92→#7B78FF, 우측으로 페이드) ─────────
y 12%    [좌 컬럼 27%]                    [본문 x=31%~96%]
          대제목 36–40px 4줄 이내          섹션 헤드라인 26px 중앙(키워드 Heavy, 일부 컬러)
          (키워드 Heavy+컬러 마침표)        태그 pill 5개(컬러 + 같은 색 글로우 그림자)
          설명 13px 3줄 이내                컬럼/표/차트 (밴드 높이 꽉 채움)
          장식 3D 오브젝트(좌하단)          하단 결론 바(컬러 테두리, 중앙 정렬 굵은 문장)
y 93%    PAPERLOGY(좌, 11px #999)                                       페이지번호(우)
```
- 태그 컬러 순서 예: 핑크 #FF2F92 / 블루 #4947FF / 그레이 #5A5B60 / 라벤더 #7B78FF / 바이올렛 #C67AFF.
- 표: 헤더 행 회색(#EFF0F2), 괘선 #D0D1DD 0.75px, 12px.
- 블루 키 컬러 버전(#4947FF): 좌측 사각 라벨(세로 2글자) + 박스 리스트 + 하단 결론 바.

### R02 다크 리포트 (#15-21, 132-135, 221-222)
- 배경 #222→#030303 세로 그라데이션 + 중앙 가로 띠(**y 150–590px**, #1F1F1F — R02·R03 공통). 본문 콘텐츠는 이 띠 안에 둔다.
- 좌측 제목: 32px, 명조풍 디스플레이(또는 Paperlogy 8) + 핑크 마침표. 좌하단 검정 광택 구체.
- 상단 섹션명 `A. 기획서의 법칙`(좌) / 소단원(우) + 1px 헤어라인.
- 본문: 태그(그레이, 활성 1개만 액센트) + 흑백 사진 카드 5개(하단 캡션). 표가 필요하면 R03을 쓴다.

### R03 데이터 매트릭스 (PEST·BCG·경쟁사 비교, #17-19)
- R02 프레임 + 우측 표/2×2 매트릭스. 열 헤더 회색 띠, 강조 셀 텍스트만 액센트. 2×2는 액센트 테두리 사분면 + 우측 A–D 설명(활성 라벨 액센트 배경).

### R04 KPI + 막대차트 + 로드맵 (투자·ROI·실행계획)
- R01 프레임(라이트). 본문 상단 y 96–192: `.kpi` 타일 3개(첫 타일만 액센트 숫자).
- 중단 y 214–602 좌(420px): `.bars` 막대차트(마지막/핵심 막대만 `.on` 액센트, 나머지 회색 #C9CAD3, 값 라벨 위).
- 우: `.roadmap` 4단계(현재 단계만 `.on`).
- 하단 y 622: `.rp-conclusion` 요청 문장. 푸터에 "예시(샘플) 수치" 표기 가능.

## 덱 리듬(시퀀스) 패턴

1. **챕터 오프너**: K01 섹션 → K09 매니페스토 ×3–6 → K02 스테이트먼트
2. **근거 전개(3요소)**: K04 ×3(하나씩 활성) 또는 K03 ×n(같은 프레임, 카드 내용만 교체)
3. **숫자 공개**: K05(맥락 문장) → K06(숫자만) — 같은 배경으로 연속
4. **페이지 쪼개기**: K07 사진만 → 사진+차트 → 사진+차트+주석
5. **보고 본문**: R01/R02 연속, 각 장 하단 결론 바
6. **엔딩**: C02(요청 + 연락처) 또는 K16 간지 톤
