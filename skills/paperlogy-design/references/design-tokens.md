- 한 장에 굵기 대비를 최소 2단계 이상 쓴다(예: 8ExtraBold 키워드 + 4Regular 조사).
- 폰트 패밀리는 한 덱에 한글 1 + 영문 1 (+필요시 손글씨 1)로 제한.

## 2. 타입 스케일 (pt, 16:9 13.33in 기준 → 1280px 캔버스에서 1pt ≈ 1.333px)

## 3. 자간·행간·정렬

- 자간(spc)은 거의 항상 음수. 0(2,883) / −2pt(2,624) / −1pt(2,541) / −3pt(1,067).
  - 40pt 제목 → spc −300 (−3pt) = **−0.075em**
  - 20pt 본문 → spc −150 = **−0.075em**
  - 96pt 히어로 → spc −600 = **−0.0625em**
  - 리포트 28pt 제목 → spc −170 = −0.06em, 12pt 본문 → −50 = −0.04em
  - CSS 권장: 제목 `letter-spacing:-0.06em`, 본문 `-0.04em`, 영문 대문자 라벨 `+0.02~0.2em`
- 행간: 100%(3,485)가 압도적. 문단만 110–150%.
  - CSS: 제목 `line-height:1.12–1.2`, 본문 `1.45–1.55`
- 정렬: 가운데(2,370) > 왼쪽(1,465) > 오른쪽(552). 양쪽정렬은 거의 안 씀(45).
  - 키노트=가운데 또는 좌측 1/3 블록, 리포트=좌측.

### 시그니처 그라데이션
- 상단 오로라: `radial-gradient(ellipse 70% 55% at 50% -5%, #7a2fa8 0%, #3a1257 35%, #000 70%)`

## 5. 효과

- 외곽 그림자 outerShdw 3,878회 — 대부분 **컬러 글로우 그림자**(태그와 같은 색, blur 크게, 투명도 높게). 회색 드롭섀도 아님.
  - CSS 태그 글로우: `box-shadow:0 6px 18px -4px color-mix(in srgb, var(--c) 70%, transparent)`
- 그라데이션 채우기 1,507회 — 평면 단색보다 미세 그라데이션 선호.
- 알파: 0%(불투명) 외에 40/30/85/15% 빈번 → 반투명 오버레이·유리 카드.
  - 글래스 카드: `background:rgba(20,22,26,.72); border:1px solid rgba(255,255,255,.08); backdrop-filter:blur(14px); border-radius:6px`
  - 사진 위 텍스트용 그라데이션 마스크: `linear-gradient(90deg, rgba(0,0,0,.85) 0%, rgba(0,0,0,.4) 45%, transparent 70%)`
- 후광 효과: 누끼 인물/제품 뒤에 큰 radial 글로우(퍼플·블루) → 고급감.
- 3D 오브젝트 장식: 리포트 좌하단 흰 큐브/홀로그램 다면체/검정 구체(라이트=흰 큐브, 다크=검정 광택 구체).

## 6. 캔버스·여백

- 16:9 고정. 사이즈는 작업 전에 확정(작업 후 변경 = 두 번 작업). 이벤트 대형 스크린은 32:9도 사용.
- 리포트 템플릿 실측(960×540 기준 비율):
  - 좌우 여백 4.5%, 상단 헤더 y=3~5%, 헤더 하단 헤어라인 y≈8.5%(핑크→퍼플 그라데이션 1px)
  - 좌측 제목 컬럼 폭 ≈ 27%, 본문 영역 x=31%~96%
  - 푸터 y≈93%: 좌 "PAPERLOGY"(9pt, 회색), 우 페이지 번호
- 키노트: 제목 블록은 좌측 기준선 x≈11% 또는 정중앙. 우측 절반에 카드/워드스택/이미지.
