# Paperlogy 61 원칙 — 실행 규칙으로 압축

원본 강의의 PRINCIPLE 01~61과 '기획서의 법칙' 파트를 장표 제작 시 바로 적용할 수 있는 규칙으로 정리했다.
`(#번호)` = 원본 슬라이드 번호(근거 장표). 원본 사진·문구는 복제하지 않는다 — 원리만 쓴다.

## 목차
A. 기획·생각 (먼저 생각하고, 글 쓰고, 마지막에 디자인)
B. 기획서의 언어 (문장)
C. 구조 (PREP·설득형·매니페스토·내로우다운)
D. 숫자 (형용사 제거)
E. 타이포그래피
F. 컬러
G. 이미지·사진
H. 레이아웃·구도
I. 강조 기술

## A. 기획·생각

- **P16 PPT는 제발 마지막에 (#175-181)**: 10일이면 5일 생각 / 3일 글쓰기 / 1일 PPT / 1일 리뷰. 빈 슬라이드부터 열면 이미 실패. → 덱을 만들기 전 반드시 메시지 원고(장당 1문장)를 먼저 쓴다. 퇴고의 마무리는 소리 내어 읽기(음독).
- **P01 가이드부터 (#7-23)**: 사이즈(16:9) 확정 → 본인 주제에 맞는 템플릿(헤더·푸터·제목 위치·태그 컬러)을 먼저 만든다. 외부 템플릿을 쓰는 건 최악의 수.
- **P08 위대한 인사이트를 위한 자료조사 (#86-93)**: 직접 경험 · 박식한 지인과 대화 · 온오프 자료 + 그 주제를 다룬 '작품'(영화·만화·소설)까지 본다.
- **P10/11 정보 말고 의견 (#94-123)**: 정보 정리는 검색이 한다. 장표마다 "그래서(So What)?"와 "왜 아직(Why Not Yet)?"를 붙여 Next Step(의견)을 낸다. 정보 박스 위에 `+ 의견` 블록을 얹는 구성(#98-99).
- **P35 PPT는 가장 중요한 것이 아니다 / P36 도구가 효과적인 순간 (#431-436)**: 실물·소리·소품이 더 강하면 슬라이드를 비우고 도구를 쓴다.

## B. 기획서의 언어

- **P21 전공이 어떻게 되세요 (#273-279)**: 내 전공 언어를 버리고 상대방의 언어로. 전문가 상대면 전문용어, 대중 상대면 일상어.
- **P22 남과 다른 단어의 힘 (#280-297)**: 본질은 그대로 두고 표현만 교체한다. 예) "다양성이 중요" → "서로 다른 각도의 선들이 모여야 입체가 된다". 장표 구성: 좌측 원칙 제목 + 우측 글래스 카드 [평범한 문장 ↓ 교체된 문장].
- **P23 위대한 기획자가 되는 세 단어 (#287-350)**: 문장구조 · 위화감 · 감정. 설득은 아이디어보다 문장구조를 더 많이 가진 쪽이 이긴다. 위화감을 미리 느끼면 해답지가 된다. 인간은 이성을 믿는 척하지만 감성에 움직인다.
- **P57 기획서의 언어 = 시와 소설의 3.5지점 (#557-571)**: 시처럼 압축하되 소설처럼 이해되게. 같은 내용을 [평서문(라이트 배경)] → [핵심어 컬러 강조 + 구조화(다크+구체)] 로 고쳐 쓰는 비포/애프터를 보여준다.
- 미사여구 금지: 프로의 기획서는 군더더기가 없고 글이 짧고 구조가 간단하다(#370).
- 흑백 인물 + 따옴표 + 서명 = 명언처럼 보인다(P54, #546-549). 인용 슬라이드에만 쓴다.

## C. 구조

- **P12 PREP (#124-127)**: 사내(일반 보고형) PPT 3요소 = 감성보다 논리 · 디자인보다 정렬 · 결론부터. Point → Reason → Example → Point.
- **P13 설득형 PPT (#138-150)**: 외부 PT용 4단계 + 감정선.
  1. 문제를 발견한다 (+위기감)
  2. 문제의 원인 파악 (+납득) — 숫자 적극 활용
  3. 문제를 해결한다 (+결단)
  4. 결론 및 기타 (+확신·사명감)
- **P14 매니페스토 (#151-165)**: 챕터 첫머리에 짧은 선언문 시퀀스(한 장 한 문장, 검정 배경, 단어 + 컬러 마침표)를 둬서 청중 머릿속에 흐름을 먼저 심는다.
- **내로우 다운 (#150, #270)**: 개요(전체 지도) → 상세 A/B/C. 매니페스토로 챕터 전체를 인식시킨 뒤 디테일로.
- **P56 원슬라이드 원메시지 (#553-556)**: 한 장에 메시지 하나. 차트 6개를 한 장에 몰지 말고 쪼갠다.
- **P06 매직넘버 3 (#70-75)**: 항목은 3개. 3개를 한 장에 다 보여주지 말고 FIFTY/NINETY/ZERO처럼 3장에 걸쳐 하나씩 밝힌다.
- **P45 페이지를 쪼갤 줄 알아야 발표력 UP (#484-490)**: 사진만 → 사진+차트 → 사진+차트+화살표처럼 같은 장을 단계별 복제해 정보를 순차 공개.

## D. 숫자

- **P03 NUMBERS (#43-49)**: 인간은 자신이 없을 때 추상을 말한다. 근거를 무슨 수를 써서라도 숫자화(댓글, FGI, 설문, 녹취).
- **P04 어디를 어떻게 숫자로 (#50-61)**: 형용사를 찾아 숫자로 바꾼다. "눈동자가 참 예쁘다" → "호감도 조사에서 9.8점". "공사장이 시끄럽다" → "소음 80dB 초과". 주관이 객관이 된다.
- 숫자는 디자인이 내용에 착 붙는 마법: 숫자형 장표는 큰 숫자(4.6 / 26년)를 히어로로 두고 근거를 작게 옆에.
- **P05 FGI & SURVEY (#62-66)**: 1단계 FGI로 가설 세우기 → 2단계 SURVEY로 숫자 근거 추출.

## E. 타이포그래피

- **P15 폰트와 덩어리감 (#166-174)**: 좋은 폰트 = Ctrl+B 없이 두께를 조절할 수 있는 패밀리. 영문은 영어 네이티브 폰트. 무료는 Pretendard·Noto Sans.
  - 덩어리감: 제목은 자간을 좁혀(−0.06em) 한 덩어리 블록으로 보이게. 여러 줄 제목은 줄 길이를 비슷하게 끊는다.
  - 한 제목 안에서 **키워드는 ExtraBold, 조사·서술어는 Regular**로 굵기를 섞는다(예: "**파워포인트 스킬**이 **향상**되지 **않는 이유**").
- **P40 폰트크기 딱 정해드립니다 (#461-463)**:
  - 큰 타이틀 38–42pt, 30자 이하 → 역동적·활동적. 넘으면 여백을 해쳐 부담.
  - 작은 타이틀 ≤25pt, 30자 이하 → 차분·품격. 더 작으면 타이틀 기능 상실.
- **P53 빅·미디엄·스몰 (#535-540)**: 같은 크기 3개(A=B=C) 대신 크기 위계(A 크게, B 중간, C 작게)로 우선순위를 보이게.
- **P41 손글씨·아날로그 (#464-468)**: 손글씨 낙서(별표·화살표·취소선 "$3.7"→낙서)로 인간미. 디지털 장표의 1~2곳에만.
- **P44 럭셔리 PPT 컨셉 (#481-483)**: 굵은 제목 → **얇은 굵기(Thin/Light) + 넓은 자간 + 흑백 이미지**로 바꾸면 럭셔리. 서브라벨은 `2 0 2 2  S E O U L`처럼 자간을 크게 벌린 영문.

## F. 컬러

- **P19 컬러 하나만 더 (#257-265)**: 브랜드 컬러가 있으면 그것. 없으면 업종 연상 컬러(IT 블루 / 식품 레드 / 건강·친환경 그린 / 유통 옐로). 표지는 강한 단색 배경 + 오브젝트 사진도 가능.
- **P26 회색은 컬러 활용의 열쇠 (#367-374)**: 활성 항목 하나만 흰색/컬러, 나머지는 회색. 단계 진행 시 현재 단계만 밝힌다.
- **P20 막힐 땐 그라디에이션 (#266-272)**: 배경이 허전하면 검정 위 오로라(퍼플/블루/그린) 그라데이션. 평면 단색 배경으로 막히지 말 것.
- **P47 슬라이드 배경 채우기 (#495-497)**: 사진을 슬라이드 배경 채우기로 깔고 그 위 반투명 도형/글래스. 그리드 점선 + 원형 글래스 버블 조합.
- 마침표 시그니처: 제목 마지막 마침표(.)만 액센트 컬러(핑크 #FF2F92 / 마젠타 #CA6093 / 레드). 원본 전체에서 반복되는 Paperlogy의 서명.

## G. 이미지·사진

- **P28 쓰고 싶은 이미지는 쓰자 / P29 잘못 쓴 이미지 하나가 전체를 망친다 (#382-390)**: 톤이 맞지 않는 클립아트·저해상도·워터마크는 금지. 덱 전체의 사진 톤(채도·명암)을 통일.
- **P51 트리밍, 사진도 퇴고 (#513-520)**: 주인공만 남기고 크롭. 배경을 흑백 처리해 주인공 컬러만 남기기. 텍스트 놓을 자리(어두운 여백 쪽)를 확보하도록 크롭.
- **P52 상하좌우에서 앞뒤로 (#521-527)**: 평면 배치 대신 깊이. 앞 인물 선명 / 뒤 인물 블러로 포커스를 이동시키며 화자 전환을 표현.
- **P32 후광효과로 고급감 (#404-409)**: 누끼 인물·제품 뒤에 퍼플/블루 radial 글로우. 검정 배경 + 후광 = 즉시 고급.
- **P30 Movie Mockup / 디바이스 목업 (#391-394, #209-211)**: 스크린샷은 폰·노트북·극장 스크린 목업 안에 넣는다. 맨 캡처 금지.
- **P31 32:9 (#395-397)**: 와이드 스크린 이벤트에서는 사진 한 장을 두 화면에 걸쳐 쓰고 큰 텍스트가 인물 뒤로 지나가게.
- 텍스트와 사진 레이어링: 큰 글자를 인물 **뒤**에 두는 깊이감(예시예종/유능제강 #205-206, 배달전문 #532).
- 섹션 구분 장표: 동일한 풀블리드 풍경(설산 야경) + `PRINCIPLE NN` 라벨 + 제목 — 덱 전체에서 같은 배경을 반복해 리듬을 만든다.

## H. 레이아웃·구도

- **P39 여백 (#455-460)**: 작은 오브젝트 하나 + 넓은 여백 = 집중. 같은 장표를 꽉 채운 버전과 비교하면 여백 버전이 고급. 단 보고형 본문 장표는 여백 금지(slide-density 적용).
- **P50 시메트리 (#504-512)**: 아름다움의 기본은 좌우 대칭. 중앙축 기준 배치, 대각선 X 가이드로 중심을 잡는다.
- **P38 선과 텍스트만 잘 써도 (#444-448)**: 가는 흰 선 하나(가로·세로)로 두 메시지를 연결/분리. 도형 없이 선+텍스트로 완성.
- **못 박기 (#170-171, #260-262, #440-441)**: 카드·사진·박스의 네 모서리에 '못'을 박아 안정감 200%. 종류: 괘선형(┏┓┗┛) · 플러스형(+) · 원형(○) · 텍스트형(A B C D).
- **P42 아날로그를 도형에서도 (#469-472)**: 완벽한 원 대신 손으로 칠한 듯한 블롭 도형.
- **P46 뉴모피즘 / P48 글래스모피즘 (#491-503)**: 뉴모피즘은 라이트 회색 배경의 볼록 버튼·번호 원. 글래스모피즘은 사진 위 반투명 블러 카드(인물 소개·데이터 패널).
- **P49 팀원 소개는 신뢰도와 직결 (#501-503)**: 밝은 배경 고품질 인물 사진 + 이름(영문 대문자, 자간 넓게) + Career/Awards 2단 리스트.
- **P43 지도 (#473-480)**: 위키미디어 SVG 지도 → 그룹 해제 → 지역별 색 채우기. 해당 지역 1곳만 컬러, 나머지 회색.

## I. 강조 기술 (P34, #421-430)

같은 문단을 놓고 강조 방법을 하나만 고른다(섞지 않음):
1. 컬러 텍스트(핵심어만 레드/핑크)
2. 굵기 대비(핵심어 Bold, 나머지 Light 회색)
3. 마침표만 컬러
4. 형광펜 하이라이트(키워드 아래 반쯤 노란 띠)
5. 이모지 치환(마침표 → 🔥)
사진 배경 위 강조는 컬러 글로우 텍스트 또는 글래스 박스.

## J. 발표·모션·도구

- **P18 동적요소는 발표의 핵심 (#237-256)**: 모션은 이미 대세. 아이콘 애니메이션(로티), 탭 내비게이션(상단 메뉴의 현재 탭을 노란 pill로 활성화 — #253-255).
- **P24/25 동영상 언제·어떤 (#351-366)**: 감정 전환·브랜드 무드에서만 짧은 루프 영상. 정보 전달용으로 쓰지 않는다.
- **P27 감성을 넣을 수 있는 귀중한 구간 (#375-381)**: 표지 · 아이스브레이킹 · 간지 · 엔딩 장표에서만 감성(명언, 풍경, 짧은 카피). 본문은 논리.
  - 간지 패턴: 어두운 풍경 + 좌상단 감성 카피(마침표 컬러) + 우상단 챕터 번호·목차 + 하단 출처.
- **P33 아이콘이냐 이모지냐 (#410-420)**: 아이콘은 한 세트(같은 선 두께)만. 이모지는 감정·캐릭터 전달용(🎾, 🔥, 🌹)으로 텍스트 안에 치환해 쓴다.
- **P37 캐릭터는 먹히는 전략 (#437-443)**: 미모지 같은 가상 캐릭터의 표정을 장표 곳곳에 넣어 화자 대리인으로.
- **P55 프레젠터 (#550-552)**: 없으면 마우스 스크롤/좌클릭.
- **툴바 세팅 (#442-443)**: 정렬·그룹·맞춤 기능을 빠른 실행 도구에 등록.
- **P58~61 (#573-608)**: 나를 위한 기획서(라이프 프로포절) — 홀로그래픽 파스텔 배경, 슬로건 장표, 2×2 포지셔닝 맵(축 라벨 + 단어 클라우드, 해당 단어만 컬러). 사람마다 해석이 다르니 대상 시각 훈련.

## 장표 단위 체크리스트 (작성 후 자가점검)

공통
1. 이 장의 메시지는 한 문장인가? (원슬라이드 원메시지)
